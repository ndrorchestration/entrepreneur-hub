## Why This Exists

This hub packages project-defined AI governance templates for builders who need structured risk, evaluation, and documentation workflows.

The templates are intended to reduce repeated governance preparation. Any claimed time savings, audit readiness, compliance alignment, or quality improvement requires evidence for the specific workflow and deployment context.

## Evidence Standard

Use:

**DEFINED → IMPLEMENTED → COMPUTED → VERIFIED → ATTESTED → HISTORICAL → HYPOTHESIS → METAPHOR → UNSUPPORTED → DEPRECATED**

A mapping to NIST AI RMF or another external framework is not certification merely because the mapping appears in a template.
